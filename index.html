About VandorNetwork

VandorNetwork was started on June 15th as a personal passion project and learning experience. The goal of this network is not to become the next massive Minecraft server overnight, but to create a fun community while learning how server development, management, and network infrastructure work. Everything has been built independently with personal time, effort, and a willingness to learn. As the network grows, new systems, improvements, and features will be added. Since this is a passion project, updates may take time, but every update is intended to improve the overall player experience. The current goal is reaching beta release and finding bugs through real player testing.
